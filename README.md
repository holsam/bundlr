# bundlr

A CLI tool for bundling files into a directory structure-aware markdown or JSON file.

## Installation
```sh
uv tool install git+https://github.com/holsam/bundlr.git
```

## Usage
Bundlr installs three CLI tools:
```sh
# Default CLI command
bundlr
# CLI command for outputting markdown bundle
bundlr-md
# CLI command for outputting JSON bundle
bundlr-js
```
